OpenGonsult Gui reference:

GTK4 window title: OpenGonsult <version>
navigation panel left side ( like gnome settings window )
main window size initially 1280 width 720p height. resizeable

Window list:
1. Dashboard 
- contains voltages, rpm, Etc meters gauges.
- gauges move dynamically according to the window size (reflows on resize)
2. graphing
- graph sources selectable in separate window found under "Sources" button (dialog window)
- graph source names and lines in different colors like in gnome-system-monitor resources tab
- each sensor gets a unique color from the palette with a labeled legend
3. Error codes
- contains error code readings and translations for them
4. settings 
- contains device selection, theme selection
